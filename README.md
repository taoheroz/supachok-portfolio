- ผลงาน: Ezy-T, Thinkwear, Product Positioning 10 รุ่น, MERCHIVE, คุโรโกะ SIM, FRIEND FIGHT
- คอนเทนต์ Facebook เรียงตามปี, Data Analytics, Resume (PDF)
- เว็บไฟล์เดียว (`index.html`) ไม่ต้อง build — ข้อมูลอยู่ใน `content/`, รูปอยู่ใน `img/` และ `book/`

