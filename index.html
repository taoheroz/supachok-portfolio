งานที่ทำ

Campaign Strategy

  • วางแผนแคมเปญ โปรโมชัน และการสื่อสาร ตามสินค้าที่ต้องเร่ง กลุ่มเป้าหมาย และวัตถุประสงค์
  • คิดคอนเซปต์และ key message แล้วแปลงเป็นคอนเทนต์ของแต่ละช่องทาง
  • วิเคราะห์จุดขายและลูกค้าเพื่อกำหนดเพอร์โซนาและ positioning พร้อมศึกษาสินค้า ราคา และโปรโมชันของคู่แข่ง

Copywriting & Content

  • วางแผนคอนเทนต์ เขียนคำโฆษณา และทำกราฟิกตามสินค้าและกลุ่มเป้าหมาย
  • ดูแลการโพสต์บน Facebook, Instagram และ YouTube ปรับข้อความและชิ้นงานให้เข้ากับแต่ละช่องทาง
  • ดูแลหน้าร้าน Shopify และข้อมูลสินค้า SKU บน WordPress

Data & Tools

  • รวบรวมและวิเคราะห์ข้อมูลใน Excel รายงานผลเพื่อปรับแผนแคมเปญ
  • ดูแล Merchant Center และ Google Tag สำหรับข้อมูลสินค้าและการติดตามเว็บไซต์
  • ใช้ ChatGPT, Claude, Codex และ Claude Code กับงานคอนเทนต์ เว็บไซต์ ข้อมูล และงานซ้ำ ๆ
